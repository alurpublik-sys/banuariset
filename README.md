# Banua Research

Stage 1 public institutional website for **Banua Research**, a research and policy knowledge platform based in Central Sulawesi, Indonesia.

## Stack
- Next.js App Router
- TypeScript
- CSS design system
- Vercel deployment target
- Supabase integration planned for Stage 2

## Stage 1 includes
- Institutional two-level navigation
- Official Banua Research logo asset
- Editorial hero carousel
- Scroll-triggered reveal motion
- Responsive publication and research sections
- Topic, data, Banua Talks, and footer sections
- Public route shells for Tentang, Riset, Publikasi, Data, Kegiatan, Kolaborasi
- Reduced-motion accessibility fallback
